# Corriger app/init : clé wex.version absente du config.yml généré

Opened: 2026-08-28
Updated: 2026-08-28
Author: agent:main

`wex app::app/init` génère un `.wex/config.yml` sans la clé `wex:` (ex: `wex:\n  version: 6.0.26`), et rien ne plante quand elle est absente. Bug localisé dans `wex-addon-app/src/wexample_wex_addon_app/.../init.py` (autour des lignes 92-99) : la clé n'est jamais écrite lors de la création.

Demande explicite de l'opérateur : corriger l'init d'abord, la migration de rattrapage (déjà trackée dans le todo `e8153ff7ac95`) vient après — ordre de priorité voulu : « Corrige l'init, on fera la migration plus tard ».

Pour récupérer/écrire la bonne valeur de version, utiliser la même technique que la commande `version/get.py` (`wex-core/src/wexample_wex_core/addons/core/commands/version/get.py`), à savoir `context.kernel.workdir.get_setup_version()` — déjà documentée dans la note `58c93ebafbc4`. Ne pas réinventer un autre mécanisme de lecture de version.

État à la fin de l'échange : le pattern correct a été identifié mais le correctif n'a pas été appliqué dans `init.py` (la conversation est partie sur un autre sujet).

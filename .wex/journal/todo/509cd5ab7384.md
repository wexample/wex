# Migration PHP : imposer declare(strict_types=1)

Opened: 2026-08-27
Updated: 2026-08-27
Author: agent:main

Décision prise en session : ne pas imposer `declare(strict_types=1)` comme règle d'écriture générale immédiate (elle changerait le comportement à l'exécution — une coercion implicite `"5"` → `int` deviendrait une `TypeError` — et créerait un parc à deux régimes si seuls les nouveaux fichiers l'appliquaient).

À la place : traiter ça comme une migration package par package parmi les ~177 fichiers PHP existants, en s'assurant que les tests PHPUnit du package restent verts après ajout de la directive. Une fois un package converti et vert, la règle `strict_types=1` devient obligatoire pour lui (peut alimenter le formatter `php-code`).

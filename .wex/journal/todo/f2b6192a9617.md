# Noms de containers : convertir les tirets du nom de projet en underscore

Opened: 2026-08-27
Updated: 2026-08-27
Author: agent:main

Le nom des containers Docker mélange les séparateurs : `{project_name}_{env}_{service}` où `project_name` garde ses tirets (kebab-case) alors que le reste utilise des underscores, ce qui donne par exemple `bdo-letters_local_vite`.

Demande : convertir les tirets de `project_name` en underscore avant de construire le nom du container, pour obtenir `bdo_letters_local_vite` (tout en underscore) au lieu de `bdo-letters_local_vite`.

Le suffixe `_local` correspond à l'environnement (`env`) et ne doit à priori jamais contenir de tiret — ce n'est donc que `project_name` qu'il faut normaliser.

Code concerné : construction du nom dans `managed_workdir.py` (méthode autour des lignes 226-232), package `wex-addon-app` — `{project_name}_{container_name}`.

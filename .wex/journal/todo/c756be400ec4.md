# own/this inutilisable en dehors de publish (addon 'system' rejeté par le résolveur)

Opened: 2026-08-27
Updated: 2026-08-27
Author: agent:main

La commande `own/this` (chown récursif) existe en v6 dans `wex-core` sous l'addon `system` (`wex-core/src/wexample_wex_core/addons/system/commands/own/this.py`), invocable en théorie via `system::own/this`.

Mais en pratique, depuis `app-manager`, ça échoue :
```
AddonNotRegisteredException: The addon 'system' is not allowed. Allowed values are: 'app', 'default'.
```
et `default::own/this` échoue aussi avec `COMMAND_RUNNER_NOT_FOUND` (la commande n'est pas dans `default`).

Le besoin initial (appliquer `own/this` avant chaque `publish` de package/suite pour éviter d'avoir à le faire manuellement) a été résolu autrement : le chown a été intégré directement dans `commands/package/publish.py` (avant `should_be_published`), ce qui couvre aussi le cas `--all-packages` puisque `publish` est appelé package par package.

Mais le problème de fond reste entier : `own/this` n'est appelable ni via `system::` ni via `default::` en dehors de ce contexte publish. Si un usage direct (hors publish) est encore nécessaire — comme en v5 — il faut soit déplacer la commande dans l'addon `default`, soit autoriser `system` dans le résolveur d'addon pour le contexte `app-manager`.

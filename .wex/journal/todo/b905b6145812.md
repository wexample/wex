# file_path()/path() : message d'erreur générique au rectify

Opened: 2026-08-27
Updated: 2026-08-27
Author: agent:main

Quand `file_path()` (à renommer `path()`) plante parce que le chemin cité n'existe pas, l'échec du `rectify` remonte en `UNEXPECTED_ERROR` générique — le chemin manquant n'apparaît que dans le crash report, pas dans le message affiché à l'utilisateur.

À améliorer : faire remonter un message clair indiquant quel chemin est manquant, plutôt qu'une erreur générique.

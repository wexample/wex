# Corriger les descriptions pyproject.toml de certains addons

Opened: 2026-08-27
Updated: 2026-08-27
Author: agent:main

En vérifiant le rendu de la nouvelle section `usage/addons.md.j2` (liste des addons dans le README de wex, tirée du `Summary` de `pyproject.toml` via `importlib.metadata`), deux problèmes de contenu sont apparus :

- `dev-css` : le `Summary` de son `pyproject.toml` est vide.
- `dev-javascript` et `dev-php` : les deux annoncent le même texte générique « Python dev addon for wex », qui ne les distingue pas et est de toute façon incorrect (ce ne sont pas des addons Python).

À corriger dans le `pyproject.toml` de chacun de ces trois addons pour que la description reflète réellement leur rôle.

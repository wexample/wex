# Chemin knowledge du prompt partagé pointe vers les sources, pas le build

Opened: 2026-08-27
Updated: 2026-08-27
Author: agent:main

Le contexte partagé livré à tout agent (`wex-addon-ai/src/wexample_wex_addon_ai/resources/ai/shared/context.j2`, rendu dans le bloc `<workspace>` de chaque agent) dit : « Accumulated project knowledge lives in `.wex/knowledge/` ». C'est faux en pratique : ce dossier ne contient que des `.md.j2`, des gabarits Jinja pleins de marqueurs — pas de la prose lisible. Un agent envoyé y lire tombe sur du templating brut.

La commande `knowledge/search` (exposée en MCP comme un outil) ne lit elle-même que `built/<langue>/`, jamais les sources `.j2`. Donc le texte du prompt partagé décrit un chemin différent de ce que l'outil utilise réellement.

À faire : changer la ligne du prompt partagé pour pointer vers `.wex/knowledge/built/en/` (le rendu à jour) plutôt que `.wex/knowledge/` (les gabarits sources). Confirmé par l'agent lui-même durant la discussion : « oui, tu as raison ».

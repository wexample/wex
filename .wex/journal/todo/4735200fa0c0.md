# Outil search invisible en /info + couverture built/en très partielle

Opened: 2026-08-27
Updated: 2026-08-27
Author: agent:main

Deux problèmes liés, découverts en fin de session, non résolus :

1. **`/info` ne montre pas l'outil `search`** parmi les outils disponibles de l'agent, alors qu'il est bien exposé en MCP à partir de la commande `knowledge/search`. Signalé comme « un vrai problème » ; l'investigation sur la manière dont les commandes sont exposées en MCP a commencé mais n'a pas abouti dans cette session.

2. **Couverture `built/en/` très incomplète** : sur les 81 apps qui ont de la documentation knowledge, seules 38 ont un `built/en/` généré. Les 43 autres n'ont jamais été construites. Conséquence directe : la recherche knowledge (`knowledge/search`, qui ne lit que `built/<langue>/`) est aveugle sur plus de la moitié des apps documentées — un agent qui cherche une réponse dans le stack via `search` peut simplement ne rien trouver parce que le build n'existe pas, pas parce que l'info n'existe pas.

À faire : soit lancer les builds manquants sur les 43 apps, soit changer de stratégie (build à la volée, alerte si absent, etc.) — la discussion s'est arrêtée avant de trancher.

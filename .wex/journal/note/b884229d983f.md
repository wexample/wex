# Préférence : garder le code mort sauf demande explicite

Written: 2026-08-29
Author: agent:main

Par défaut, un agent ne doit pas supprimer du code mort de sa propre initiative même s'il devient inutile après une modification (ex : condition qui rend une option comme `--clear-cache` inopérante). Le garder évite de casser des scripts existants qui utilisent encore cette option.

La suppression ne doit se faire que sur demande explicite de l'utilisateur. Exemple concret : l'agent avait laissé `--clear-cache` en place (devenue no-op après un changement forçant `--no-cache` systématique) ; l'utilisateur a dû dire explicitement « vire le dead code stp » pour que l'agent la retire.

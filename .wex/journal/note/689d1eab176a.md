# Règle de présentation README wex

Written: 2026-08-27
Author: agent:main

Le README de wex doit présenter le programme par ce qu'il fait (applications et services Docker, état des projets, paquets, serveurs, bases, agents) et par sa grammaire unique, jamais comme un noyau vide dont les fonctionnalités viendraient des plugins/addons — l'exemple donné à éviter : « Odoo est une coquille vide, allez voir dans les plugins pour choisir ce qu'il fait ». Ne pas mentionner le format TOML dans cette description. Cette règle a été inscrite dans le contrat du README pour qu'aucun agent ne réintroduise ce cadrage.

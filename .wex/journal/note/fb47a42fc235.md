# _content.md.j2 : composeur du README knowledge

Written: 2026-08-27
Author: agent:main

Architecture retenue pour la génération du README à partir de `.wex/knowledge/` (remplace les noms de section en dur et la clé `readme.sections` du config.yml de suite, qui n'existait de toute façon pas).

**Principe** : le README n'est qu'un extrait du knowledge, pas tout le knowledge. Un fichier `_content.md.j2` dans `.wex/knowledge/readme/` sert de compositeur explicite : s'il existe, il pilote tout le rendu du README (rien d'autre n'est ajouté automatiquement) ; s'il n'existe pas, le comportement historique (découverte + agrégation des sections) s'applique en fallback. Câblé dans `readme_content_config_value.py::get_templates()` :
```python
def get_templates(self):
    context = self._get_template_context()
    if self._composer_exists():
        return [self._render_composed(context)]
    return self._render_discovered(context)
```

**Convention de nommage** : tout fichier préfixé `_` est ignoré par `_discover_sections()` (donc `_content.md.j2` ne pollue jamais le rendu par découverte automatique).

**Variables disponibles dans le contexte du template** (`app_readme_config_value.py:152`) : `package_name`, `project_name`, `version`, `description`, `homepage`, `license_info`, `dependencies`, `workdir`.

**Extends vers un template parent (addon/wex)** : possible car le `FileSystemLoader` couvre déjà les 4 niveaux de cascade. Contrainte : le parent doit avoir un **nom différent** de l'enfant. Si les deux s'appellent `_content.md.j2`, `{% extends %}` retombe sur le même match (celui du workdir) et boucle. Convention proposée : le parent générique s'appelle `_layout.md.j2` (avec des `{% block content %}`), l'enfant spécifique `_content.md.j2` fait `{% extends "_layout.md.j2" %}`.

**Nettoyage effectué en même temps** : `readme/introduction.md` supprimé (doublon dégradé de `usage/introduction.md`) ; `usage/introduction.md` renommé en `usage/installation.md` et recentré sur son sujet réel ; les sous-sections de test extraites vers `usage/testing.md`.

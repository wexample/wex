# Composeur README silencieux sur fragments orphelins

Written: 2026-08-27
Author: agent:main

Le composeur de knowledge court-circuite la découverte de fichiers : tout `.wex/knowledge/readme/<nom>.md` dont le nom ne figure pas explicitement dans la liste d'`include` du template n'est plus jamais lu ni rendu, sans erreur ni avertissement. Ça permet d'accumuler de la documentation écrite (parfois longue, ex. `wex-addon-app` avait 359 lignes de fragments orphelins) qui n'apparaît nulle part dans le README final.

À vérifier/surveiller à chaque ajout de fragment `readme/` dans un package (Python, PHP ou JS) : s'assurer qu'il est bien référencé dans la liste `include` du template composeur, sinon il devient invisible silencieusement.

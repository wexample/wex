# Dossiers .pdm-build root-owned bloquent l'install editable pdm

Written: 2026-08-27
Author: agent:main

Des dossiers `.pdm-build/` peuvent se retrouver possédés par `root` (probablement créés par un build lancé depuis un container Docker qui mappe root), ce qui fait planter `pdm`/`pip install -e` avec `PermissionError` au moment où pdm tente de nettoyer son dossier de build avant de reconstruire (`shutil.rmtree` sur `.pdm-build`).

Fix : supprimer ces dossiers avec `sudo rm -rf .pdm-build` dans les packages concernés (ce sont de simples artefacts de build, pdm les recrée). Pas de fix automatique en place — si ça se reproduit, chercher d'abord ce symptôme avant de creuser plus loin.

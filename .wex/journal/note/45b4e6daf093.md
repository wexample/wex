# Tests filestate : chemin ressources dépend du CWD pytest

Written: 2026-08-28
Author: agent:main

Les tests `filestate` utilisent `_get_package_root_path()` qui vaut `f"{os.path.abspath(os.curdir)}{os.sep}"` — le chemin des ressources de test est donc relatif au répertoire depuis lequel `pytest` est lancé, pas au package.

Conséquence pratique : lancer `pytest` depuis `PACKAGES/PYTHON/` (au lieu de la racine du package `packages/filestate/`) fait chercher les ressources dans `PACKAGES/PYTHON/tests/resources/`, qui n'existe pas — les vraies ressources sont dans `packages/filestate/tests/resources/`. Le fichier attendu (ex. `simple-text.txt`) n'est jamais copié dans `tmp_path`, et l'inférence de type échoue silencieusement, produisant des échecs qui ressemblent à une vraie régression alors qu'ils viennent uniquement du CWD.

À vérifier systématiquement avant de diagnostiquer un échec de test filestate comme une régression : relancer depuis la racine du package concerné.

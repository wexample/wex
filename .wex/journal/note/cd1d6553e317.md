# get_shortcut removal — quelle constante utiliser pour registry.json

Written: 2026-08-27
Author: agent:main

Complète le todo existant `4200529472fa` (Supprimer get_shortcut — registre workdir).

Pour remplacer l'accès via `get_shortcut()` au fichier `registry.json`, utiliser :

```python
from wexample_app.const.path import APP_DIR_NAME_TMP
... = self.get_path() / APP_DIR_NAME_TMP / "registry.json"
```

`APP_DIR_NAME_TMP` (package `wexample_app`) et `CORE_DIR_NAME_TMP` (package wex-core) valent tous les deux `Path("tmp")` — choix décidé pour `APP_DIR_NAME_TMP` car c'est la couche la plus upstream (déjà utilisé ainsi dans `_init_registry` du kernel).

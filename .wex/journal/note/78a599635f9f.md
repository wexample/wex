# Formatters PHP/JS ajoutés (style code)

Written: 2026-08-27
Author: agent:main

Les règles de nommage classes/fichiers déjà en place pour Python (`python-code`) ont été généralisées à PHP et JS, sous la même forme, enregistrées via `FormatterContributingAddonMixin` pour être injectées automatiquement à tout agent éditant un fichier correspondant (hook `PreToolUse`) :

| formatter | matches | excluded |
|---|---|---|
| `php-code` | `.php` sous le `src/` d'un `composer.json` | `vendor/` |
| `javascript-code` | `.ts`/`.tsx`/`.js`/`.jsx` sous le `src/` d'un `package.json` | `node_modules/` |

Les règles ont été écrites à partir des vrais packages existants, pas inventées : PSR-4 fichier-est-classe + dossiers `Class/ Helper/ Traits/ Interface/ Enum/` pour PHP ; classe en PascalCase par fichier pour JS. La revue des anciennes règles legacy sur le sujet 'coding style' a été faite, les règles jugées obsolètes écartées, et la sous-tâche correspondante close.

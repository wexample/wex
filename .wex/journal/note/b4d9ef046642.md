# pdm.lock peut apparaître malgré un crash pdm (complète 3265276205bb)

Written: 2026-08-28
Author: agent:main

Complète la note `3265276205bb` (Dossiers .pdm-build root-owned bloquent l'install editable pdm).

Un `pdm.lock` est apparu dans un package alors que le projet utilise `uv` (pas `pdm`, pas `bun`). Cause : une commande `pdm install -G dev` (lancée pour installer pytest) a planté avec un `PermissionError` sur `.pdm-build/`, mais **a quand même écrit `pdm.lock` sur disque avant de crasher**.

À retenir : un crash pdm lié à `.pdm-build/` root-owned n'empêche pas forcément l'écriture du lockfile. Si un `pdm.lock` réapparaît dans un package qui utilise `uv`, ce n'est pas forcément une réintroduction volontaire de pdm — vérifier la date du fichier et le lien avec une commande pdm récente avant de s'inquiéter, puis le supprimer.

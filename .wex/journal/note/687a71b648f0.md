# Commande de régénération du README d'un package

Written: 2026-08-27
Author: agent:main

Pour régénérer le README d'un package depuis son dossier :

```bash
wex app::state/rectify --yes --filter-path README.md
```

Options utiles :
- `--app-path /chemin/vers/le/paquet` pour lancer sans se déplacer dans le dossier du paquet.
- `--all-packages` pour traiter toute une suite d'un coup (à lancer depuis la suite).
- Retirer `--yes` pour confirmer chaque écriture, ou ajouter `--dry-run` pour prévisualiser sans écrire.

Le README est généré via le composeur partagé `PACKAGES/.wex/knowledge/package-readme/_content.md.j2`, qui gouverne désormais le README des 89 paquets sans qu'aucun dépôt n'ait de fichier à lui.

# Convention nommage commandes : underscores fichiers, tirets appels

Written: 2026-08-27
Author: agent:main

Convention wex pour le nommage des commandes : les fichiers de commande sous `commands/` utilisent des underscores, mais l'appel de la commande (namespace) utilise des tirets.

Exemple donné par l'opérateur :
```
app::nique/ta-mere  >  commands/nique/ta_mere.py
```

Cette convention est la clé de lecture d'un bug où `build_command_from_parts` recevait moins de parties que prévu (3 attendues) — le mapping tiret→underscore doit être fait lors de la résolution du chemin fichier depuis le nom de commande appelé (voir `COMMAND_SEPARATOR_FUNCTION_PARTS`, `build_command_from_function`).

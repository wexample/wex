# Import obsolète pdf_generator.__main__ après renommage (SYRTIS pdf-generator)

Written: 2026-08-27
Author: agent:main

Ceci est du travail restant à faire, pour le projet SYRTIS, package utilitaire `pdf-generator` (chemin `SYRTIS/project/utilities/pdf-generator`), pas pour wex.

Après le renommage du module Python `pdf_generator` en `syrtis_pdf_generator`, le fichier `src/syrtis_pdf_generator/http_server.py` ligne 7 importe encore l'ancien nom : `from pdf_generator.__main__ import _default_jobs_dir, cmd_generate`, ce qui casse le serveur (`ModuleNotFoundError: No module named 'pdf_generator'`) même après rebuild Docker sans cache. Le rebuild seul ne suffisait pas — la vraie cause est ce reliquat de renommage dans le code source.

À faire : corriger cet import (et auditer le reste du package pour d'autres occurrences de l'ancien nom `pdf_generator` non renommées), puis vérifier que le serveur HTTP démarre correctement en conteneur.

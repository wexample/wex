# app-manager : runner restreint (app+default only)

Written: 2026-08-27
Author: agent:main

Quand on exécute une commande depuis `app-manager` (le binaire local à un package, ex. `.wex/bin/app-manager` ou l'exécution directe depuis un dossier de package comme PACKAGES/PYTHON), le contexte chargé n'est pas celui du CLI `wex` complet : seuls les addons `app` et `default` sont chargés.

C'est un choix voulu — `app-manager` est un runner restreint, un sous-ensemble léger dédié à la gestion d'une app, pas l'environnement complet. Des addons comme `system` (qui contient par exemple `own/this`) ne sont donc pas disponibles dans ce contexte, même s'ils existent et fonctionnent avec le CLI `wex` global.

À savoir si on cherche pourquoi une commande connue du CLI `wex` semble « manquante » ou introuvable quand on est dans le dossier d'un package et qu'on invoque `app-manager` directement.
